# Switchyard releases

Installable packages of Switchyard, a control panel for terminal coding agents: a `.deb` and an
`.rpm` for Linux (x86_64), a `.dmg` for macOS (Apple Silicon) and an installer `.exe` for Windows
(x64).

Download them from the [latest release](https://github.com/TheRealMierzen/switchyard-releases/releases/latest).
Once installed, Switchyard offers each new release in its sidebar and updates itself.

This repository only holds the releases; it has no source code.
